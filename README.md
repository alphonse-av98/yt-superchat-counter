# YouTube Live 課金リアルタイム集計ツール（OBSオーバーレイ対応）

YouTube Live 配信中に受け取った **Super Chat**・**Super Sticker**・**各種ギフト課金（ジュエル・プレゼント系）** の金額をリアルタイムで自動集計し、**配信者向け管理ダッシュボード** と **OBS ブラウザソース用オーバーレイ** の両方に表示できるローカル実行型 Web ツールです。

- **APIキー不要・クォータ制限なし**（`youtubei.js` によるライブチャット購読）
- **メンバーシップ関連は完全除外**（新規加入・継続マイルストーン・メンバーシップギフトは金額・件数ともに集計対象外）
- **多通貨の日本円換算**（`.env` で為替レートを自由に変更可能）
- **ローカル自動保存 ＆ CSV 出力**（サーバー再起動時のセッション復元、Excel で文字化けしない UTF-8 BOM 付き CSV）

---

## 動作環境

- **OS:** Windows / WSL2 (Ubuntu) / macOS / Linux
- **Node.js:** v18.0.0 以上（**v20 LTS 推奨**）
- **npm:** v9 以上

---

## インストール手順

1. リポジトリ（またはプロジェクトフォルダ）へ移動します。

```bash
cd yt-superchat-counter
```

2. 依存パッケージをインストールします。

```bash
npm install
```

3. 環境変数ファイルを作成します。

```bash
# PowerShell の場合
Copy-Item .env.example .env

# WSL2 / Bash の場合
cp .env.example .env
```

必要に応じて `.env` を編集し、ポート番号や為替レートを調整してください。

---

## 起動方法

### 開発モードで起動（ファイル変更時に自動再起動）

```bash
npm run dev
```

### ビルドして本番起動

```bash
npm run build
npm start
```

起動するとコンソールに以下の URL が表示されます（デフォルトポート `3000`）。

- **管理ダッシュボード:** `http://127.0.0.1:3000/`
- **OBS オーバーレイ画面:** `http://127.0.0.1:3000/overlay`

## 基本的な使い方

1. ブラウザで管理ダッシュボード（`http://127.0.0.1:3000/`）を開きます。
2. YouTube Live の配信 URL（例：`https://www.youtube.com/watch?v=...`、`https://www.youtube.com/live/...`）または 11 文字の動画 ID を入力し、**「監視開始」** をクリックします。
3. 配信中に Super Chat / Super Sticker / ギフト課金が飛ぶと、管理画面と OBS オーバーレイがリアルタイムで更新されます。
4. 配信終了後や集計を保存したいときは、履歴欄の **「CSVダウンロード（UTF-8 BOM付）」** から集計データを保存できます。
5. 次回の配信前に集計をゼロへ戻す場合は **「集計リセット」** を押してください。

### 配信外での動作確認（テストモード）

`.env` で `ENABLE_TEST_MODE=true`（初期値）になっている場合、管理画面右上の **「テスト表示: OFF」** トグルボタンからテストパネルを開閉できます（普段は非表示になっています）。

- **集計対象ボタン（緑）:** 円・米ドル・台湾ドルの Super Chat、Super Sticker、ジュエル系ギフトを擬似発生させ、円換算と OBS カウントアップを確認できます。
- **除外対象ボタン（グレー）:** メンバーシップ新規加入・継続・メンバーシップギフトを擬似発生させ、合計金額・課金件数に加算されず正常に除外されることを確認できます。
- **演出テストボタン:** 目標達成時の紙吹雪エフェクトを OBS オーバーレイ上で即座にプレビューできます。

※ 実配信時に誤クリックを防ぎたい場合は、トグルを OFF にしたままにするか、`.env` で `ENABLE_TEST_MODE=false` に変更して再起動してください。

### 目標額設定と達成時の紙吹雪エフェクト

- 管理画面の **「目標額設定」** カードから目標金額（円）と **表示 ON/OFF スイッチ** を設定できます（変更は即座に OBS オーバーレイへ反映され、`data/session.json` にも自動保存されます）。
- 目標額表示が ON の状態で合計金額が目標額に到達すると、**OBS オーバーレイの最前面に被せる形で紙吹雪エフェクトが継続表示** されます（管理画面側では紙吹雪を表示せず、トースト通知のみ行います）。
- 達成後にさらに高い目標額（ストレッチゴール）へ引き上げるか、集計リセット・目標表示 OFF を行うと紙吹雪は自然に停止します。

## OBS ブラウザソースへの登録方法

OBS Studio の「ソース」一覧から **「＋」→「ブラウザ」** を追加し、以下の通り設定してください。

| 設定項目 | 推奨値 |
|---|---|
| **URL** | `http://127.0.0.1:3000/overlay` |
| **幅（Width）** | `480`（必要に応じて調整） |
| **高さ（Height）** | `160`（必要に応じて調整） |
| **カスタムCSS** | 初期値のままで問題ありません（ページ側で `background: transparent` を設定済みです） |
| **表示されていないときにソースをシャットダウン** | チェックを外す（常時WebSocket接続を維持するため推奨） |

### オーバーレイの見た目調整（URL クエリパラメータ）

OBS に登録する URL の末尾にパラメータを付けるだけで、配信レイアウトに合わせて簡単に調整できます。

| パラメータ | 指定できる値 | 初期値 | 説明 |
|---|---|---|---|
| `color` | `white`, `#ffeb3b`, `cyan` 等 | `#ffffff` | 文字色 |
| `align` | `left`, `center`, `right` | `left` | 横方向の配置 |
| `valign` | `top`, `middle`, `bottom` | `top` | 縦方向の配置 |
| `size` | `18` 〜 `180`（px数値） | `56` | 金額の文字サイズ |
| `goalSize` | `14` 〜 `120`（px数値） | `size` の約48%（約27px） | 目標額・達成率の文字サイズを個別調整したい場合に指定 |
| `bg` | `badge`, `dark`, `light`, `none` | `badge` | 背景スタイル（`badge`=ゆめかわオーロラ、`dark`=ナイトオーロラ、`light`=コットンホワイト、`none`=完全透過文字のみ） |
| `stroke` | `on`, `strong`, `off` | `on` | 文字の縁取り強度（`bg=none` 時は自動で `strong` になります） |
| `label` | 任意の文字列 / `none` | `SUPER CHAT TOTAL` | 上部のラベル文字（`none` で非表示） |
| `goal` | `off` | 管理画面に連動 | `off` を指定すると管理画面が ON でもこのソース上では目標額を非表示 |
| `duration` | `100` 〜 `3000`（ms） | `650` | カウントアップ演出の時間 |

**カスタマイズ例:**

- 右寄せ・背景なし・縁取り強め・黄色文字・ラベル非表示：
  ```text
  http://127.0.0.1:3000/overlay?align=right&bg=none&stroke=strong&color=%23ffeb3b&label=none
  ```
- 中央寄せ・小さめサイズ・日本語ラベル：
  ```text
  http://127.0.0.1:3000/overlay?align=center&size=44&label=%E6%9C%AC%E6%97%A5%E3%81%AE%E5%BF%9C%E6%8F%B4%E5%90%88%E8%A8%88
  ```

## 為替レート・設定のカスタマイズ（`.env`）

起動時に API キー不要の公開為替レート API（プライマリ：`open.er-api.com`、予備：`currency-api (jsDelivr)`）から **160通貨以上の最新レートを自動取得** します。管理画面の「レート再取得」ボタンから再起動なしで再取得することもできます。

- オフライン環境や API 障害時は、エラー終了せず内蔵の概算レートへ自動フォールバックします。
- 自動取得を無効化したい場合は `.env` に `AUTO_FETCH_EXCHANGE_RATES=false` を設定してください。
- 特定の通貨だけ手動レートで固定したい場合は、`.env` 内の `RATE_<通貨コード>` のコメントを外して指定します（手動指定は自動取得より優先されます）。

```env
PORT=3000
AUTO_FETCH_EXCHANGE_RATES=true
RATE_JEWEL=1.5

# 特定通貨のみ固定したい場合の例
# RATE_USD=150
# RATE_TWD=4.7
```

- 定義されていない通貨が届いた場合でもアプリは停止せず、元通貨・元金額は履歴に記録され、管理画面上に「レート未設定」と表示されます。必要に応じて `RATE_<通貨コード>` または `EXCHANGE_RATES_JSON` に追加してください。

---

## データ保存と復元

- 集計データはイベント受信・リセットのたびに `data/session.json` へ自動保存されます。
- サーバーを再起動しても前回の合計金額・履歴は自動的に復元されます。
- `data/*.json` は `.gitignore` で除外されているため、配信データが誤って Git コミットされることはありません。

## イベント判定仕様（フィルタリング）

| 区分 | 対象イベント | 処理 |
|---|---|---|
| **集計対象** | Super Chat (`LiveChatPaidMessage`) | 金額を円換算して加算・履歴記録 |
| **集計対象** | Super Sticker (`LiveChatPaidSticker`) | 金額を円換算して加算・履歴記録 |
| **集計対象** | その他ギフト課金（ジュエル・プレゼント系等） | 金額またはジュエル数を円換算して加算・履歴記録 |
| **完全除外** | メンバーシップ新規加入 / 継続マイルストーン (`LiveChatMembershipItem`) | 金額・件数とも完全除外 |
| **完全除外** | メンバーシップギフト購入 / 受取 (`LiveChatSponsorshipsGift*`) | 金額・件数とも完全除外 |

※ YouTube 側の新ギフト形式の内部構造を確認したい場合は、`.env` に `DEBUG_CHAT_EVENTS=true` を設定すると受信したチャットイベントの生構造をコンソールへ出力できます。
